# Doro · 打个螺丝 · 修订4

一个面向手机和桌面浏览器的螺丝解谜小游戏。拆开叠放的玻璃板，把螺丝按颜色装盒，再用收集到的材料填完画册。

[在线玩 · 修订4](https://doro.suki520.com/)

修订 4 主线包含 8 关和 1,020 颗螺丝。第一关先装满一盒，第二关是 120 颗的墙；过不去可以用免费辅助。完成第二关后开放残局解围和主题挑战。游戏支持长按检查、缩放、键盘视图操作、颜色辅助与轻柔动效。进度保存在当前浏览器中，可通过游戏菜单导出和导入恢复记录。

本仓库中的可见名称统一为「Doro · 打个螺丝 · 修订4」（站点标题、首页页脚、本说明与 `package.json` 的 description）。包版本号 `4.0.0` 仍表示客户端存档世代，与内容修订号不是同一件事。

## 本地开发

使用 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址。游戏使用 TypeScript、Vite 和 Phaser。

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1
# 或对已构建的 dist 做手机/桌面静态检查（含存档恢复脚本）：
npm run check-release
```

将 `dist/` 的内容部署到静态 HTTP 服务即可。仓库中的 `src/` 包含游戏逻辑和界面，`public/campaign/` 保存关卡数据（生产包只复制当前修订，R1 三十关仍留在源码与测试中），`public/runtime/` 保存运行素材，`tests/` 包含规则、物理、存档和操作相关测试。默认测试会跑完修订 4 全部八关的官方线物理见证，并抽样主题精修/残局。

画册高清原图会打进静态包，但只在画册里点「欣赏高清原图」时按需加载，不计入首屏。

## 公开站点检索

线上站点若仍带有托管层的 `x-robots-tag: noindex, nofollow`，搜索引擎不会收录。这是用户的公开作品站，本仓库**默认不**在页面或预览服务器里加入 noindex，也**不会**自行改动线上托管头。若希望被搜索到，在托管平台（或 CDN / 反向代理）去掉该响应头即可；若希望继续不收录，保持现有头，或在 `index.html` 增加 `<meta name="robots" content="noindex, nofollow">`。是否上线改动由站点所有者决定。
