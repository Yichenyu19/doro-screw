## 简介

一款免费、无广告的螺丝解谜小游戏。拆开钉住的零件，把同色螺丝装进盒子里；主线八关，第一关先装满一盒，第二关是墙；也可输入挑战码重开同一盘面。

Doro 是《胜利女神：妮姬》（NIKKE）角色 Dorothy 的同人形象，不是官方作品，与 SHIFT UP 或 NIKKE 官方没有合作或授权关系。本应用不收费、不投放广告、不收集论坛以外的账号密码。

## 版本说明（1.0.0，首个正式候选）

- 独立微应用运行包：主线八关、主题挑战、挑战码、画册（含高清图）、本地存档。
- 存档走平台 `sdk.localStorage`（按应用及正式/沙盒隔离）。导出存档在用户同意时使用 `files.save`。
- 页面隐藏时自动暂停。使用原生 Web Audio，已申请 `audio.webAudio`，声音输出交给平台会话开关。
- 不申请剪贴板与外链权限：挑战码改为长按全选复制。
- 含画册高清图（包内按需读取）。不含旧修订关卡包、网站 favicon/og，也没有外部统计或未声明网络请求。
- 提示与预分析在主线程运行，不创建 Worker。

## 权限用途（提审备注可粘贴）

| 权限 | 用途 |
| --- | --- |
| `theme.read` | 读取社区语言、背景色、减少动效和明暗偏好，在离开时取消订阅。 |
| `storage.read` / `storage.write` | 读写本局进度、设置和撤回日志。不跨设备同步，不用原生 Cookie，也不使用可能越出隔离范围的原生 IndexedDB。 |
