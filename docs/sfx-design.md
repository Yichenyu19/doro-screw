# 声音设计说明（修订 4 · 混音 v3）

听力状态：**未经人耳验收。** 本说明只依据检索证据（下载量、评分数、上传者描述）、ffmpeg / 脚本测量（时长、真峰值、RMS、400 ms K 加权、频谱重心、起止点击、叠加峰值）与分层混音规则，不能代替人耳验收。试听文件、叠加混音、合成后备与频谱图在 `/workspace/doro-screw-review/sfx-v3/`。发行文件是 `public/sfx/*.ogg`，十八个短采样合计 **96 124 字节（0.092 MiB）**，低于 1.5 MiB 上限。

门限（按 audio-mixing / procedural-audio / cartoon-sfx-track）：短音效的 Integrated LUFS 常落到 −70，不以它作为通过条件。实际门限是 **真峰值 ≤ −1 dBTP**、起止采样绝对值 ≤ 0.03、叠加场景在限幅后同样不超过 −1 dBTP。分层用 400 ms 门限的 K 加权功率。运行时另有分类总线、压缩与限幅、按类别抖动、5 路复音上限（低优先级被抢）、同类短间隔合并，以及在装满 / 通关时对动作总线的短暂闪避。

## 对照 skill 的差距与本轮改动

按 sxsound 的 `sfx-sources`、`procedural-audio`、`audio-mixing` 与 yc-skills 的 `cartoon-sfx-track` 逐条对照 v2 实现后，本轮做了这些事。

| Skill 要求 | v2 差距 | v3 做法 |
| --- | --- | --- |
| sfx-sources：按票数与声源描述选材，只用可商用许可；UI 优先 Kenney | 采样来源本身站得住。Kenney / Pixabay 仍 403，未取得官方包 | 沿用已核实的 Freesound CC0 与 Mixkit 音效许可素材。新事件（撤回、界面确认、画册、暂存满）优先程序化合成，体积更小 |
| procedural-audio：听不到就要测；48 kHz / 24-bit 试听；频谱图；短音效用峰值和分层，不要靠 Integrated LUFS | v2 有峰值表，无频谱图、无起止点击检测、无合成后备渲染 | `scripts/measure-sfx.py` 输出 WAV、频谱图、K 加权、重心、点击、叠加与合成后备 |
| audio-mixing：先留余量，切 200–500 Hz 浑与 2–5 / 5–9 kHz 刺耳，总线合并后检查峰值，短 SFX 看峰值，披露未耳听 | 采样直通 `destination`，多声可叠加过载；金属高频偏亮 | 分类增益 → 3:1 压缩 → −1.5 dB 限幅 → 主音量 0.9。金属动作声用 2–3 极低通。所有叠加场景真峰值合格 |
| cartoon-sfx-track：高频动作要克制；同时声部有上限；微变速；交付必须写未经人耳验收；许可可追溯 | 复音 6 且只踢最老的；入盒 / 揭示 / 连击偏响；缺撤回、画册、暂存满；THIRD-PARTY-NOTICES 未列音效 | 复音 5，按优先级抢占。入盒改 C–E–G 阶梯并压响。揭示、连击明显让出装满与通关。补齐事件。许可写入 ASSETS 与 THIRD-PARTY-NOTICES |

Kenney、Pixabay 本环境仍不可达，与 v2 相同，发行包不含这两处文件。

## 来源、许可与选择

检索方法与 v2 相同，见当时对 Freesound / Mixkit 候选的票数和描述。本轮没有引入新的第三方文件，只重新裁切、均衡、分层和合成。下载原文件仍只作构建输入，不进仓库，路径 `/tmp/doro-sfx-raw/`。构建脚本：`scripts/build-sfx.py`。计量脚本：`scripts/measure-sfx.py`。

沿用（均为裁切、均衡与限幅后的短片段）：

- 拧出：Freesound 353245、442313、181635（CC0）
- 松开：Freesound 706440（CC0），辅以 181635
- 入盒叮：Freesound 220179（CC0），叠 C5 / E5 / G5
- 装满 / 通关玻璃：Mixkit 2936（Mixkit 音效许可）
- 落地 / 破墙板：Mixkit 3158、835、833（Mixkit 音效许可）
- 揭示上行：Freesound 422516（CC0），增益已大幅降低
- 辅助塑料：Freesound 63531、448393（CC0）
- 卡住卡扣：Freesound 582904（CC0）
- 回流 / 撤回：Freesound 822397（CC0）；撤回再倒放并加下行噪声扫

合成层（Web Audio 配方，采样缺失时离线渲染同一套）承担音阶、谁osh、界面嘀声和暂存满的低闷音。未使用 BY-NC。Kenney、Pixabay 仍未取得。

## 运行时混音

`src/audio.ts` 在第一次用户手势里创建 `AudioContext`，同步播放一帧静音缓冲以照顾 iOS / 自动播放策略，再加载 `public/sfx`。采样失败则回退到 `SYNTH_RECIPES`。页面隐藏时停声并挂起上下文，回到前台再解锁。开关只改主音量并挂起或恢复，失败不影响任何游戏动作。

总线：动作 0.85、冲击 0.95、奖励 1.00、警告 0.75、界面 0.58，主音量 0.9。奖励里优先级 ≥ 8 的声音（装满、通关、破墙）会把动作总线在约 260 ms 内闪避到 0.38。通关与破墙几乎不抖音高，以免和弦走音。

请用仓库外的试听 WAV 听一遍再定稿。若某条过亮、过闷或与画面错位，应改 `scripts/build-sfx.py` 的裁切或增益后重编，不要直接拉高运行时音量。
