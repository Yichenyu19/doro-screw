# 修订 3 合成音效计量

这些数字来自用 Python 按 `src/audio.ts` 中 `SYNTH_RECIPES` 离线渲染的 48 kHz / 24-bit 单声道参考 WAV，再用 ffmpeg `ebur128=peak=true` 与频谱峰值读取。游戏运行时仍是 Web Audio 即时合成，不随包分发采样。

**没有用耳朵听过。** 短音效的 Integrated LUFS 会被门限打到约 -70，不能用来判断响度，只以真峰值、样本峰值和频谱峰作为对照。层次设计是：整板落地最强，入盒/拧出居中，回流与露出更轻、更亮，单钉松开最弱、更低。
